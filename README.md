# ternatelomba
TernateLomba adalah aplikasi mobile berbasis Android yang menjadi platform terpusat untuk mencari informasi lomba, melakukan pendaftaran, serta mengajukan dan mengelola lomba secara digital melalui sistem verifikasi administrator, sehingga memudahkan peserta dan penyelenggara dalam mengakses informasi dan mengelola kegiatan perlombaan secara terstruktur.

## Pembagian tugas
Milestone 1 - Autentikasi login/register dan navigasi setelah login ke beranda:
1. Teguh - authScreen
2. Nisa - splashScreen
3. Putry - Beranda
4. Adit - Backend dan konfigurasi penghubung flutter dan database di beberapa file
5. Lina - Main dan appTheme
6. Valdo - Widgets

Milestone 2 - Membuat navigasi, logika di beberapa panel utama dan integrasi flutter dan database pada profile
1. Teguh - Profile page/history registrasi
2. Adit - Edit lomba
3. Lina - Informasi lomba
4. Putry - Polish Beranda/notification
5. Valdo - Navigasi dan panel ajukan lomba
6. Nisa - Navigasi panel lomba saya
